# Five Elements Value Circulation Model

The Five Elements Value Circulation Model maps Royalty OS value circulation
onto the classical cycle of Wood, Fire, Earth, Metal, and Water.

This model is not used as mysticism.

It is used as a structural metaphor for dynamic equilibrium, value circulation,
and civilizational stability.

---

## 1. Purpose

The purpose of this model is to describe how value moves through a full
civilizational cycle.

In Royalty OS Payment Rail Bridge v0.1, value does not begin as money.

Value begins as a question, structure, idea, or seismic source.

It then moves through resonance, trace, scoring, allocation, payment rails,
and returns to generate new questions.

```text
Question → Resonance → Trace → Allocation → Payment Flow → New Question
```

The Five Elements model gives this circulation a stable conceptual structure.

---

## 2. Element Mapping

| Element | Civilization Layer | Meaning |
|---|---|---|
| Wood | Origin Layer | Questions, structures, seismic sources |
| Fire | Resonance Layer | Diffusion, cultural heat, attention |
| Earth | Trace Layer | Institutions, protocols, records |
| Metal | Allocation Layer | Scoring, crystallization, value logic |
| Water | Payment Rail Layer | Liquidity, settlement, circulation |

---

## 3. Generative Cycle

The generative cycle describes how one layer gives rise to the next.

```text
Wood → Fire → Earth → Metal → Water → Wood
```

This is the main circulation loop of the model.

---

## 4. Wood: Questions, Structures, and Seismic Sources

Wood represents the birth of value.

It includes:

- new questions
- new ideas
- new structures
- new protocols
- new creative works
- new conceptual frameworks
- new human-AI collaborative artifacts

Wood is the layer of emergence.

In Royalty OS terminology, Wood corresponds to the origin or seismic source.

A new question creates the possibility of new value.

```text
Wood = origin of value
```

### Wood Generates Fire

When a question or structure appears, it may begin to resonate.

That resonance produces cultural heat.

Thus, Wood generates Fire.

---

## 5. Fire: Resonance, Diffusion, and Cultural Heat

Fire represents the spread of value through attention and resonance.

It includes:

- diffusion
- discussion
- citation
- imitation
- reinterpretation
- cultural heat
- AI reference
- network amplification

Fire is the layer where a source begins to affect others.

A question becomes valuable not only because it exists,
but because it changes how others think, speak, build, or create.

```text
Fire = resonance of value
```

### Fire Generates Earth

Resonance becomes stable only when it leaves traces.

Discussion, citation, reuse, reference, and influence begin to form records.

Thus, Fire generates Earth.

---

## 6. Earth: Institutions, Protocols, and Trace

Earth represents stabilization.

It includes:

- trace records
- protocols
- logs
- archives
- institutions
- review systems
- dispute paths
- provenance references

Earth is the layer where influence becomes recordable.

Without Earth, resonance disappears like heat without memory.

In Royalty OS architecture, Earth corresponds to the trace and institutional layers.

```text
Earth = stabilization of value
```

### Earth Generates Metal

When traces become stable, they can be reviewed, compared, scored, and structured.

This makes value more precise.

Thus, Earth generates Metal.

---

## 7. Metal: Scoring, Allocation, and Value Crystallization

Metal represents crystallization.

It includes:

- scoring
- contribution assessment
- allocation logic
- impact evaluation
- seismic score
- tolerance bands
- review outcomes
- value distribution rules

Metal is the layer where trace becomes structured allocation.

It does not mean that value becomes perfectly measurable.

It means that value becomes sufficiently structured for review-aware allocation.

```text
Metal = crystallization of value
```

### Metal Generates Water

Once value has been crystallized into allocation logic,
it can be prepared for circulation.

Thus, Metal generates Water.

---

## 8. Water: Payment Rails, Liquidity, and Value Flow

Water represents circulation.

It includes:

- payment rails
- liquidity
- settlement
- wallets
- P2P payment systems
- micropayments
- programmable settlement
- agent-native payment flows
- XMoney as one possible payment-rail candidate

Water is the layer where value flows back to recipients.

However, Water does not define value by itself.

Payment rails circulate value after the origin, resonance, trace, scoring,
allocation, and review layers have prepared the conditions for circulation.

```text
Water = circulation of value
```

### Water Generates Wood

When value returns to creators, agents, maintainers, communities,
or other contributors, it may nourish the next question.

This creates new origin points.

Thus, Water returns to Wood.

---

## 9. Full Generative Loop

The full generative loop can be written as follows:

```text
Wood  → Question / Structure / Seismic Source
Fire  → Resonance / Diffusion / Cultural Heat
Earth → Institution / Trace / Protocol
Metal → Scoring / Allocation / Value Crystallization
Water → Payment Rail / Liquidity / Value Flow
Wood  → New Question
```

In simplified form:

```text
Question
   ↓
Resonance
   ↓
Trace
   ↓
Allocation
   ↓
Payment Flow
   ↓
New Question
```

This is the value circulation loop.

## 10. Control Cycle

The Five Elements model also includes a control cycle.

The control cycle prevents the system from becoming unbalanced.

```text
Wood controls Earth
Fire controls Metal
Earth controls Water
Metal controls Wood
Water controls Fire
```

In this architecture, the control cycle can be interpreted as follows.

---

### Wood Controls Earth

Questions and structures should challenge institutions.

However, they should not destroy institutional stability completely.

```text
Inquiry must renew institutions without dissolving them.
```

---

### Fire Controls Metal

Resonance and cultural heat should influence value judgment.

However, hype should not melt allocation logic.

```text
Attention must not replace evaluation.
```

---

### Earth Controls Water

Institutions, protocols, and dispute paths should regulate value flow.

However, they should not freeze circulation.

```text
Governance must guide liquidity without blocking it.
```

---

### Metal Controls Wood

Scoring and allocation should recognize value.

However, value metrics should not dominate inquiry.

```text
Measurement must not enslave questions.
```

---

### Water Controls Fire

Payment flows and liquidity may amplify attention.

However, money should not overheat resonance into manipulation.

```text
Liquidity must not become artificial hype.
```

---

## 11. Dynamic Equilibrium

The purpose of the Five Elements Value Circulation Model is dynamic equilibrium.

A healthy value circulation system requires:

- Wood to keep generating new questions
- Fire to spread meaningful resonance
- Earth to preserve trace and stability
- Metal to crystallize value responsibly
- Water to circulate value without erasing context

If one layer dominates, the system becomes distorted.

If one layer disappears, the circulation breaks.

The model therefore emphasizes balance rather than domination.

---

## 12. XMoney in the Water Layer

XMoney is interpreted in this repository as one possible payment-rail candidate
within the Water layer.

This does not mean:

- XMoney is required by Royalty OS
- XMoney is officially integrated with this architecture
- XMoney alone determines value
- XMoney replaces trace, scoring, allocation, or dispute layers

It means only that XMoney may be structurally relevant as a wallet-like,
P2P-oriented, payment-rail candidate for future value circulation.

Correct framing:

```text
XMoney may become one possible payment rail candidate
for Royalty OS-compatible value circulation.
```

Incorrect framing:

```text
XMoney is the official payment layer of Royalty OS.
```

---

## 13. Relationship to Payment Rail Bridge

The Payment Rail Bridge sits between Metal and Water.

```text
Metal → Payment Rail Bridge → Water
```

Metal produces allocation logic.

Water circulates value.

The Payment Rail Bridge translates allocation intent into payment-compatible
instructions while preserving trace, review, and dispute context.

This is why the bridge is necessary.

Without the bridge, allocation cannot safely become circulation.

---

## 14. Civilizational Interpretation

This model describes a civilization where value is not treated as a static object.

Value is treated as circulation.

In the old model, money often represents ownership transfer.

In this model, money represents the return flow of value to its sources.

```text
Old model:
Ownership → Transaction → Profit

Circulation model:
Question → Resonance → Trace → Allocation → Flow → New Question
```

This does not abolish markets.

It adds a deeper layer beneath them:

```text
value as trace-aware circulation
```

---

## 15. Non-Mystical Use of the Five Elements

This specification uses the Five Elements as a structural metaphor.

It does not require religious, mystical, or metaphysical assumptions.

The model is useful because it provides:

- a generative cycle
- a control cycle
- a balance model
- a way to visualize feedback loops
- a language for dynamic equilibrium

The Five Elements model is therefore used here as an architectural pattern.

---

## 16. Summary

The Five Elements Value Circulation Model defines the circulation logic of
Royalty OS Payment Rail Bridge v0.1.

```text
Wood  = Question
Fire  = Resonance
Earth = Trace
Metal = Allocation
Water = Payment Flow
```

The complete loop is:

```text
Question → Resonance → Trace → Allocation → Payment Flow → New Question
```

In this model, payment rails such as XMoney do not create value by themselves.

They circulate value after the other layers have made circulation meaningful.

The purpose of the model is not merely to move money.

The purpose is to keep civilization capable of generating new questions.
